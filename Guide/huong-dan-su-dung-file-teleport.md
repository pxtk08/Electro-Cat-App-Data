Bước 1: Bạn cần tải file mà bạn cần về. Bạn có thể tìm thấy trong ⁠[📦 · Kho File](#/files) & ⁠[🤝 · Kho File Cộng Đồng](#/community), hoặc bạn có thể tải từ các nguồn khác. Tùy bạn.
![mô tả ảnh](img/huong-dan-1-mwbrm053.png)
Bước 2: Bạn cần giải nén file ra, vì các file gửi thường ở dạng ZIP. Chuột phải vào file và chọn 'Extract All' (Giải nén tất cả), một cửa sổ sẽ xuất hiện.
![mô tả ảnh](img/image-mwbrwzm5.png)
Bước 3: Sau khi giải nén, một thư mục sẽ xuất hiện. Bấm vào thư mục đó.
![mô tả ảnh](img/image-mwbrxxqr.png)
Bước 4: Bên trong thư mục, bạn sẽ thấy một file như thế này. Nhấp đôi chuột vào nó để tiếp tục.
![mô tả ảnh](img/image-mwbry6s1.png)
Bước 5: Cuối cùng, sẽ có 2 file bên trong. Nhấp đôi chuột vào 'Readme' để mở lên và đọc kỹ tất cả các lưu ý bên trong trước khi chuyển sang bước tiếp theo.
![mô tả ảnh](img/image-mwbryni9.png)
Bước 6: Sau đó chuột phải vào file Waypoint và chọn Copy (Sao chép).
![mô tả ảnh](img/image-mwbrzwgc.png)
Bước 7: Sau khi xong, chọn Ổ C:, sau đó tìm kiếm 'Uni' trên thanh tìm kiếm ở góc trên bên phải.
![mô tả ảnh](img/image-mwbs0c0l.png)
Bước 8: Mở thư mục ra bạn sẽ thấy giao diện như thế này. Dán file bạn vừa copy vào đây. Chỉ có thể để MỘT FILE ở đây cùng một lúc.
![mô tả ảnh](img/image-mwbs1c5y.png)
Bước 9: Sau đó khởi động Launcher và vào game. Sau khi mở lần đầu, giao diện sẽ trông như thế này. Chuyển sang tab Teleport.
![mô tả ảnh](img/image-mwbs1pzj.png)
Bước 10: Chuyển sang tab Warning trước và bật tính năng này lên, sau đó bạn mới có thể sử dụng chức năng Teleport.
![mô tả ảnh](img/image-mwbs26hw.png)
Bước 11: Sau khi bật, chuyển sang tab Custom, giao diện sẽ trông như thế này.
![mô tả ảnh](img/image-mwbs2ls1.png)
Bước 12: Một lưu ý quan trọng là bạn cần bật General, hãy chắc chắn rằng bạn đã bật nó.
![mô tả ảnh](img/image-mwbs2z05.png)
Bước 13: Sau khi bật xong, nhấn 'Load Item' là bạn đã hoàn thành việc nạp file vào.
![mô tả ảnh](img/image-mwbs3beq.png)
Bước 14: Mình khuyên bạn nên gán phím tắt cho 3 nút này bằng cách chuột phải vào chúng.
![mô tả ảnh](img/image-mwbs3okk.png)
Bước 15: Gán phím theo cách tiện nhất cho bạn, hoặc cài đặt như mô tả trong file Readme bạn vừa đọc (hoặc file bạn vừa bỏ qua và giờ mới mở ra đọc sau khi làm đến đây ==).
![mô tả ảnh](img/image-mwbs44gm.png)
Bước 16: Bạn có thể lưu Config của mình vào thư mục Config bằng nút 'Create New'. Lần sau mở lên, chỉ cần Load Config là tất cả cài đặt đã lưu trước đó sẽ được khôi phục, không cần làm lại từ đầu.
![mô tả ảnh](img/image-mwbs4i5z.png)
Thế là xong! Để chạy file tiện hơn, bạn có thể điều chỉnh các cài đặt tính năng và bật các chức năng khác trong Uni. Hãy dành chút thời gian kiểm tra từng tab và tab phụ để xem Uni có những chức năng gì nhé.
